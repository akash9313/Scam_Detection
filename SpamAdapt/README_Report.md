## 2. Compilation Instructions

The document is written using standard LaTeX packages (`amsmath`, `amssymb`, `booktabs`, `tabularx`, `tikz`, `listings`, `cite`, `hyperref`). It can be compiled using any modern TeX distribution (**TeX Live**, **MiKTeX**, or **MacTeX**) or directly uploaded to **Overleaf**.

### Option A: Standard Two-Pass `pdflatex` + `bibtex` (Command Line)

From the `SpamAdapt/` directory:

```bash
# 1. First LaTeX compilation pass
pdflatex SpamAdapt_Report.tex

# 2. Process BibTeX citations
bibtex SpamAdapt_Report

# 3. Second LaTeX compilation pass (resolve references)
pdflatex SpamAdapt_Report.tex

# 4. Third LaTeX compilation pass (resolve cross-references & TikZ layouts)
pdflatex SpamAdapt_Report.tex
```

### Option B: Automated Build via `latexmk`

```bash
latexmk -pdf SpamAdapt_Report.tex
```

To clean intermediate build files (`.aux`, `.bbl`, `.blg`, `.log`, `.out`):
```bash
latexmk -c SpamAdapt_Report.tex
```

### Option C: Online Compilation via Overleaf

1. Go to [Overleaf](https://www.overleaf.com) and create a new project.
2. Upload `SpamAdapt_Report.tex` and `references.bib`.
3. Set the compiler to **pdfLaTeX** (default) and TeX Live version to **2023** or **2024**.
4. Click **Recompile**.
